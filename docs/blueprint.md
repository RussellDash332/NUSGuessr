# **App Name**: NUSGuessr

## Core Features:

- Image Display: Display a random image of a location within the National University of Singapore (NUS) campus. Images will be obtained from a pre-existing, curated image repository. 
- Interactive Map Guessing: Allow users to guess the location by pinpointing it on an interactive map interface.
- Location Reveal: Reveal the actual location on the map after the user guesses.
- Distance Calculation: Calculate and display the distance between the user's guess and the actual location.
- Scoring System: Calculate and display a score based on the accuracy of the user's guess. The closer the guess, the higher the score.

## Style Guidelines:

- Primary color: Vibrant green (#90EE90) to represent the lush campus environment of NUS.
- Background color: Light grey (#F0F0F0) to provide a clean and unobtrusive backdrop.
- Accent color: A slightly darker shade of green (#80c980), analogous to the primary, to highlight interactive elements and calls to action.
- Body and headline font: 'Inter' for a modern and readable sans-serif font suitable for both headings and body text.
- Use simple, clear icons to represent map markers, scoring, and other interactive elements.
- A clean and intuitive layout with the image prominently displayed above the interactive map.
- Subtle animations to provide feedback on user interactions, such as zooming and pinpointing locations.
